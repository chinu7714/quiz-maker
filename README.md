# 🚀 Quiz Maker (AI-Powered Quiz Platform)

> An intelligent, real-time quiz platform powered by AI for smart learning, competition, and performance tracking.

---

## 📌 Overview

**Quiz Maker** is a full-stack AI-powered web application that enables users to generate, play, and analyze quizzes dynamically. The platform integrates modern technologies with AI to deliver an engaging and personalized learning experience.

It is designed for students, educators, and competitive exam aspirants, providing real-time quiz gameplay, analytics, and scalable SaaS-style architecture.

---

## ✨ Features

### 🤖 AI Capabilities
- AI-generated quiz questions (topic-based)
- Open-ended and MCQ quiz support
- Smart fallback question system

### 🎮 Core Functionality
- Real-time quiz gameplay
- Multiplayer quiz support (Socket.IO)
- Live leaderboard system
- Quiz history tracking

### 📊 Analytics & User Experience
- Performance analytics dashboard
- Topic-wise progress tracking
- Modern SaaS-style UI (Tailwind CSS)
- Responsive and fast interface

### 🏆 Advanced Features
- Notifications system
- Badges & achievements
- Quiz reviews and ratings
- Premium user features (Razorpay integration)

### 🔐 Authentication & Security
- Google Login (NextAuth)
- Secure session management
- Protected API routes

---

## 🛠️ Tech Stack

| Layer        | Technology |
|-------------|-----------|
| Frontend     | Next.js, React, Tailwind CSS |
| Backend      | Node.js, API Routes |
| Database     | PostgreSQL / MySQL (Prisma ORM) |
| Auth         | NextAuth (Google OAuth) |
| AI           | OpenAI API / Groq API |
| Realtime     | Socket.IO |
| Payments     | Razorpay |
